.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["一"] 學習、規劃和收集資料
[role="quick-margin-para"]
與您的 NetApp 帳戶代表合作，了解各種選項並規劃您的新 StorageGRID 系統。請考慮以下類型的問題：

[role="quick-margin-list"]
* 您預計初始階段和後續階段分別儲存多少物件資料？
* 您需要多少個站點？
* 每個站台需要多少個節點以及哪些類型的節點？
* ${post_edited_translations.segment}
* 誰會使用您的網格來儲存物件？他們會使用哪些應用程式？
* 您對安全性或儲存設備有任何特殊要求嗎？
* 您是否需要遵守任何法律或監管要求？


[role="quick-margin-para"]
您也可以選擇與您的 NetApp 專業諮詢服務顧問合作，存取 NetApp ConfigBuilder 工具以完成組態工作簿，以便在安裝和部署新系統時使用。您也可以使用此工具來協助自動化任何 StorageGRID 應用裝置的組態。請參閱 https://docs.netapp.com/us-en/storagegrid-appliances/installconfig/automating-appliance-installation-and-configuration.html["自動化應用裝置安裝與組態"^]。

[role="quick-margin-para"]
審查 link:index.html["了解 StorageGRID"] 和 link:../network/index.html["${post_edited_translations.segment}"]。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["二"] 安裝節點
[role="quick-margin-para"]
StorageGRID 系統由獨立的硬體節點和軟體節點組成。首先，您需要為每個應用裝置節點安裝硬體，並設定每個 Linux 或 VMware 主機。

[role="quick-margin-para"]
若要完成安裝，您必須在每個應用裝置或軟體主機上安裝 StorageGRID 軟體，並將節點連線至網格。在此步驟中，您需要提供站台與節點名稱、子網路詳細資料，以及 NTP 和 DNS 伺服器的 IP 位址。

[role="quick-margin-para"]

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-5.png["五"] 設定 ILM
[role="quick-margin-para"]
您可以透過設定資訊生命週期管理 （ILM） 原則來控制 StorageGRID 系統中每個物件的放置位置和保存期限，此原則包含一或多條 ILM 規則。ILM 規則指示 StorageGRID 如何建立和發佈物件資料的複本，以及如何隨時間管理這些複本。

[role="quick-margin-para"]
瞭解如何：link:../ilm/index.html["使用 ILM 管理物件"]
