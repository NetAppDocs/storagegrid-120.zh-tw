= 移除 StorageGRID 中的自訂警示規則
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果您不再想使用自訂警報規則，可以將其移除。

.開始之前
* 您已使用 link:../admin/web-browser-requirements.html["支援的網頁瀏覽器"] 登入 Grid Manager。
* 您擁有 link:../admin/admin-group-permissions.html["管理警報或 Root 存取權限"]。


.步驟
. 選擇 *Alerts* > *Rules*。
+
顯示「警報規則」頁面。

. 選擇要移除的自訂警示規則的選項按鈕。
+
您無法移除預設警示規則。

. 選擇*移除自訂規則*。
+
出現確認對話框。

. 選擇 *OK* 以移除警示規則。
+
任何作用中的警示執行個體將在 10 分鐘內解決。
