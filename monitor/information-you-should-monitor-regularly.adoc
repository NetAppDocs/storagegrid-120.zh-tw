= 在 StorageGRID 中監控什麼和何時監控
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
即使 StorageGRID 系統在發生錯誤或部分網格無法使用時仍能繼續運作，您也應該在潛在問題影響網格效率或可用度之前加以監控並解決。

.開始之前
* 您已使用 link:../admin/web-browser-requirements.html["支援的網頁瀏覽器"] 登入 Grid Manager。
* 您有link:../admin/admin-group-permissions.html["特定存取權限"]。
