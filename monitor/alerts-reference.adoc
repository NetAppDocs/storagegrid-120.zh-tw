= StorageGRID 中的警示
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
此參考清單列出了 Grid Manager 中顯示的預設警示。您收到的警示訊息中包含建議的動作。

根據需要，您可以建立自訂警示規則，以符合您的系統管理方法。

一些預設警報使用link:commonly-used-prometheus-metrics.html["Prometheus 指標"]。
