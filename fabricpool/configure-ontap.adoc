= 配置 ONTAP System Manager，將 StorageGRID 新增為 FabricPool 雲端層
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
取得所需的 StorageGRID 資訊後，您可以前往 ONTAP 將 StorageGRID 新增為雲端分層。

.開始之前
* 如果您已完成 FabricPool 設定精靈，您將擁有已下載的 `ONTAP_FabricPool_settings___bucketname__.txt`檔案。
* 如果您手動設定了 StorageGRID，則您需要提供 StorageGRID 的完整網域名稱 （FQDN） 或 StorageGRID HA 群組的虛擬 IP （VIP） 位址、負載平衡器端點的連接埠號碼、負載平衡器憑證、租戶帳戶 root 使用者的存取金鑰 ID 和秘密金鑰，以及 ONTAP 將在該租戶中使用的儲存貯體名稱。




[[access-ontap-system-manager]]
== 存取 ONTAP System Manager

這些說明介紹如何使用 ONTAP System Manager 將 StorageGRID 新增為雲端分層。您也可以使用 ONTAP CLI 完成相同的組態。如需說明，請前往  https://docs.netapp.com/us-en/ontap/fabricpool/index.html["ONTAP FabricPool 文件"^]。

.步驟
. 存取要分層到 StorageGRID 的 ONTAP 叢集的 System Manager。
. 以叢集系統管理員身分登入。
. 導覽至 *STORAGE* > *Tiers* > *Add Cloud Tier*。
. 從物件存放區供應商清單中選取 *StorageGRID*。




[[enter-storagegrid-values]]
== 輸入 StorageGRID 值

請參閱 https://docs.netapp.com/us-en/ontap/fabricpool/index.html["ONTAP FabricPool 文件"^]以取得更多資訊。

.步驟
. 使用  `ONTAP_FabricPool_settings___bucketname__.txt` 檔案或您手動取得的值，完成「新增雲端分層」表單。
+
[cols="1a,3a"]
|===
| 欄位 | 說明 


 a| 
Name
 a| 
請為此雲端層輸入唯一名稱。您可以接受預設值。



 a| 
URL 樣式
 a| 
如果您 link:../admin/configuring-s3-api-endpoint-domain-names.html["已設定的 S3 端點網域名稱"]，請選取 *Virtual Hosted-Style URL*。

*Path-Style URL* 是 ONTAP 的預設值，但建議針對 StorageGRID 使用虛擬託管樣式請求。如果您在 *Server name (FQDN)* 欄位中提供 IP 位址而非網域名稱，則必須使用 *Path-Style URL*。



 a| 
伺服器名稱（FQDN）
 a| 
輸入您用於 StorageGRID 的完整網域名稱 （FQDN） 或 StorageGRID HA 群組的虛擬 IP （VIP） 位址。例如， `s3.storagegrid.__company__.com`。

請注意下列事項：

** 您在此處指定的 IP 位址或網域名稱必須與您為 StorageGRID 負載平衡器端點上傳或產生的憑證相符。
** 如果您提供網域名稱，DNS 記錄必須對應至您將用來連線至 StorageGRID 的每個 IP 位址。請參閱 link:configure-dns-server.html["設定 DNS 伺服器"]。




 a| 
SSL
 a| 
已啟用（預設）。



 a| 
物件存放區憑證
 a| 
貼上您用於 StorageGRID 負載平衡器端點的憑證 PEM，包括：
`-----BEGIN CERTIFICATE-----` 和  `-----END CERTIFICATE-----`。

*注意：* 如果 StorageGRID 憑證是由中介 CA 所發行，您必須提供中介 CA 憑證。如果 StorageGRID 憑證是由根 CA 直接發行，您必須提供根 CA 憑證。



 a| 
連接埠
 a| 
輸入 StorageGRID 負載平衡器端點所使用的連接埠。ONTAP 連接到 StorageGRID 時將使用此連接埠。例如，10433。



 a| 
存取金鑰和私鑰
 a| 
輸入 StorageGRID 租戶帳戶的 root 使用者的存取金鑰 ID 和秘密存取金鑰。

*提示*：如果您日後在 StorageGRID 中產生新的存取金鑰和私密存取金鑰，請先在 ONTAP 中輸入新金鑰，然後再從 StorageGRID 刪除舊值。否則， ONTAP 可能會暫時失去對 StorageGRID 的存取權限。



 a| 
Container 名稱
 a| 
輸入您為此 ONTAP 分層建立的 StorageGRID 儲存貯體名稱。

|===
. 在 ONTAP 中完成最後的 FabricPool 組態。
+
.. 將一個或多個 Aggregate 附加至雲端分層。
.. （可選）建立 Volume 分層原則。
