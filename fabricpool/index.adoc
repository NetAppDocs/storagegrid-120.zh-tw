= 使用 StorageGRID 搭配 FabricPool 的設定工作流程
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果您使用 NetApp ONTAP 軟體，可以使用 NetApp FabricPool 將閒置資料分層到 NetApp StorageGRID 物件儲存系統。

請依照以下步驟操作：

* 瞭解為 FabricPool 工作負載設定 StorageGRID 的考量事項與最佳實踐。
* 了解如何設定 StorageGRID 物件儲存系統以搭配 FabricPool 使用。
* 了解如何在將 StorageGRID 作為 FabricPool 雲端分層附加時，向 ONTAP 提供所需的值。

[[what-is-fabricpool]]
== 什麼是 FabricPool？

FabricPool 是一種 ONTAP 混合式儲存解決方案，使用高效能快閃記憶體彙總作為效能分層，並使用物件存放區作為雲端分層。使用啟用 FabricPool 的彙總有助於在不影響效能、效率或保護的前提下降低儲存設備成本。

FabricPool 將雲端分層（外部物件存放區，例如 StorageGRID）與本機分層（ONTAP 儲存設備彙總）關聯起來，以建立磁碟的複合集合。FabricPool 內的 Volume 可利用分層功能，將作用中（熱）資料保存在高效能儲存設備（本機分層）上，並將非作用中（冷）資料分層儲存至外部物件存放區（雲端分層）。

無需進行任何架構變更，您可以繼續從中央 ONTAP 儲存系統管理您的資料和應用程式環境。



[[what-is-storagegrid]]
== StorageGRID 是什麼？

NetApp StorageGRID 是一種將資料作為物件進行管理的儲存架構，這與其他儲存架構（例如檔案或區塊儲存）截然不同。物件儲存在單一 Container（例如儲存桶）中，而不是像檔案一樣嵌套在目錄中的目錄內。雖然物件儲存的效能通常低於檔案或區塊儲存，但它的易擴充性卻顯著更高。StorageGRID 儲存桶可容納 PB 級的資料和數十億個物件。



[[why-use-storagegrid-as-a-fabricpool-cloud-tier]]
== 為什麼選擇 StorageGRID 作為 FabricPool 雲端分層？

FabricPool 可以將 ONTAP 資料分層到多個物件儲存提供者，包括 StorageGRID。與公有雲可能在儲存桶或 Container 層級設定最大每秒輸入 / 輸出作業次數 （IOPS） 不同，StorageGRID 的效能會隨著系統中節點數量的增加而擴展。將 StorageGRID 用作 FabricPool 雲端分層，可讓您將冷資料儲存在自己的私有雲中，以獲得最佳效能並完全控制您的資料。

此外，當您使用 StorageGRID 作為雲端分層時，不需要 FabricPool 授權。
