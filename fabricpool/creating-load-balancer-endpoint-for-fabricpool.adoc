= 在 StorageGRID 中為 FabricPool 建立負載平衡器端點
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
StorageGRID 使用負載平衡器來管理來自用戶端應用程式（例如 FabricPool）的工作負載。負載平衡可最大化多個儲存節點的速度和連線容量。

在設定 StorageGRID 以搭配 FabricPool 使用時，您必須設定負載平衡器端點，並上傳或產生負載平衡器端點憑證，此憑證用來確保 ONTAP 與 StorageGRID 之間安全的連線。

若要使用 FabricPool 設定精靈完成此工作，請前往link:use-fabricpool-setup-wizard-steps.html["存取並完成 FabricPool 設定精靈"]。

.開始之前
* 您已使用 link:../admin/web-browser-requirements.html["支援的網頁瀏覽器"] 登入 Grid Manager。
* 您有link:../admin/admin-group-permissions.html["${post_edited_translations.segment}"]。
* 您已審閱了總覽link:../admin/managing-load-balancing.html["負載平衡的考量因素"]以及link:best-practices-for-load-balancing.html["適用於 FabricPool 的負載平衡最佳實務做法"]。

|===
. 在「選擇綁定模式」步驟中，指定綁定模式。綁定模式控制如何存取端點，是使用任意 IP 位址，還是使用特定的 IP 位址和網路介面。
+
[cols="1a,3a"]
|===
| 模式 | 說明 


 a| 
全域（預設）
 a| 
用戶端可以使用任何閘道節點或管理節點的 IP 位址、任何網路上任何 HA 群組的虛擬 IP （VIP） 位址或對應的 FQDN 存取端點。

除非您需要限制此端點的存取能力，否則請使用 *全域* 設定（預設值）。



 a| 
HA 群組的虛擬 IP
 a| 
用戶端必須使用 HA 群組的虛擬 IP 位址（或對應的 FQDN）才能存取此端點。

具有此綁定模式的端點都可以使用相同的連接埠號，只要您為端點選擇的 HA 群組不重疊即可。



 a| 
節點介面
 a| 
用戶端必須使用所選節點介面的 IP 位址（或對應的 FQDN）來存取此端點。



 a| 
節點類型
 a| 
根據您選擇的節點類型，用戶端必須使用任何管理節點的 IP 位址（或對應的 FQDN）或任何閘道節點的 IP 位址（或對應的 FQDN）來存取此端點。
