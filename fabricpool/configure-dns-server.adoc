= 使用 FabricPool 為 StorageGRID 配置 DNS 伺服器項目
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
設定高可用度群組、負載平衡器端點和 S3 端點網域名稱後，您必須確保 DNS 包含 StorageGRID 所需的項目。您必須為安全性憑證中的每個名稱以及您可能使用的每個 IP 位址加入 DNS 項目。

請參閱 link:../admin/managing-load-balancing.html["負載平衡的考慮因素"]。



[[dns-entries-for-storagegrid-server-name]]
== StorageGRID 伺服器名稱的 DNS 項目

新增 DNS 條目，將 StorageGRID 伺服器名稱（完整網域名稱）與您將使用的每個 StorageGRID IP 位址關聯。您在 DNS 中輸入的 IP 位址取決於您是否使用負載平衡節點的 HA 群組：

* ${post_edited_translations.segment}
* 如果您未使用 HA 群組，ONTAP 可以使用任何閘道節點或管理節點的 IP 位址連線至 StorageGRID 負載平衡器服務。
* 如果伺服器名稱解析到多個 IP 位址，ONTAP 會與所有 IP 位址（最多 16 個 IP 位址）建立用戶端連線。建立連線時，IP 位址會以輪詢方式隨機選擇。




[[dns-entries-for-virtual-hosted-style-requests]]
== ${post_edited_translations.segment}

如果您已定義link:../admin/configuring-s3-api-endpoint-domain-names.html["${post_edited_translations.segment}"]並將使用虛擬託管風格的請求，請為所有必要的 S3 端點網域名稱（包括任何萬用字元名稱）新增 DNS 條目。
