= StorageGRID 的內部網格節點通訊
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
StorageGRID 內部防火牆允許傳入連線至網格網路上的特定連接埠。負載平衡器端點定義的連接埠也接受連線。


NOTE: NetApp 建議您啟用網格節點之間的網際網路控制訊息協定 (ICMP) 通訊。允許 ICMP 通訊可以提高無法存取某個網格節點時的故障轉移效能。

除了 ICMP 和表中列出的連接埠外，StorageGRID 還使用虛擬路由器備援通訊協定 (VRRP)。VRRP 是一種網際網路傳輸協定，使用 IP 協定編號 112。StorageGRID 僅在單點傳播模式下使用 VRRP。只有在設定了link:../admin/managing-high-availability-groups.html["高可用度組"]時才需要 VRRP。



[[guidelines-for-linux-based-nodes]]
== Linux 節點指南

如果企業連網策略限制了對這些連接埠的存取，您可以在部署時間使用部署組態參數重新對應連接埠。如需連接埠重新對應和部署組態參數的詳細資訊，請參閱 link:../swnodes/index.html["在基於軟體的節點上安裝 StorageGRID"]。


NOTE: 已取代對連接埠重新對應的支援，且將在未來的版本中移除。若要移除重新對應的連接埠，請參閱 link:../maintain/removing-port-remaps-on-bare-metal-hosts.html["移除裸機主機上的連接埠重映射"]。



[[guidelines-for-vmware-based-nodes]]
== 基於 VMware 的節點指南

只有在需要定義 VMware 連網外部的防火牆限制時，才設定下列連接埠。

如果企業連網原則限制對這些連接埠中任何一個的存取，您可以在使用 VMware vSphere Web Client 部署節點時重新對應連接埠，或在自動化網格節點部署時使用組態檔案設定。如需更多關於連接埠重新對應和部署組態參數的資訊，請參閱 link:../swnodes/index.html["在 VMware 上安裝 StorageGRID"] 的說明。


NOTE: 已取代對連接埠重新對應的支援，且將在未來的版本中移除。若要移除重新對應的連接埠，請參閱 link:../maintain/removing-port-remaps-on-bare-metal-hosts.html["移除裸機主機上的連接埠重映射"]。



[[guidelines-for-appliance-nodes]]
== 應用裝置節點指南

如果企業連網原則限制對任何這些連接埠的存取，您可以使用 StorageGRID Appliance Installer 重新對應連接埠。請參閱 https://docs.netapp.com/us-en/storagegrid-appliances/installconfig/optional-remapping-network-ports-for-appliance.html["選用：重新對應應用裝置的網路連接埠"^]。


NOTE: 連接埠重新映射支援已棄用，將在未來的版本中移除。若要移除已重新映射的連接埠，請參閱link:../maintain/removing-port-remaps.html["移除 StorageGRID 應用裝置上的連接埠重映射"]。
