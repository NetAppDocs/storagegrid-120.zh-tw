= StorageGRID 的網路閘道需求
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
請遵循以下網路閘道或路由器的要求和準則。

* 如果已設定，則指定網路的閘道必須位於該特定網路的子網路內。
* 如果使用靜態位址設定介面，則必須指定除 0.0.0.0 之外的閘道位址。
* 如果沒有閘道，最佳實務做法是將閘道位址設定為網路介面的 IP 位址。
