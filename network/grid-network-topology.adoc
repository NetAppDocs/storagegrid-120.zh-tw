= StorageGRID 的網格網路拓撲
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
最簡單的網路拓撲是僅設定網格網路來建立。

設定網格網路時，需要為每個網格節點的 eth0 介面建立主機 IP 位址、子網路遮罩和閘道 IP 位址。

組態過程中，必須將所有網格網路子網路新增至網格網路子網路清單 (GNSL) 中。此清單包含所有網站的所有子網路，也可能包含提供對 NTP、DNS 或 LDAP 等關鍵服務存取的外部子網路。

在安裝時，Grid Network 介面會套用 GNSL 中所有子網路的靜態路由，如果已設定 Grid Network 閘道，則會將節點的預設路由設定為該閘道。如果沒有 Client Network，且 Grid Network 閘道是節點的預設路由，則不需要 GNSL。系統也會產生至網格中所有其他節點的主機路由。

在此範例中，所有流量都共用同一個網路，包括與 S3 用戶端請求以及管理和維護功能相關的流量。


NOTE: 此拓撲適用於外部無法存取的單一站台部署、概念驗證或測試部署，或者當第三方負載平衡器充當用戶端存取邊界時。可能時，Grid Network 應專門用於內部流量。Admin Network 和 Client Network 都有額外的防火牆限制，可封鎖外部流量存取內部服務。支援將 Grid Network 用於外部用戶端流量，但此用途提供的保護層級較少。
