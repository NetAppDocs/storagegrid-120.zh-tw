= StorageGRID 的外部通訊
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
用戶端需要與網格節點通訊以擷取和擷取內容。所使用的連接埠取決於所選的物件儲存協定。這些連接埠必須對用戶端可存取。



[[restricted-access-to-ports]]
== 連接埠存取受限

如果企業連網策略限制了對任何連接埠的存取，您可以執行以下操作之一：

* 使用 link:../admin/configuring-load-balancer-endpoints.html["負載平衡器端點"] 以允許在使用者自訂連接埠上進行存取。
* 部署節點時需要重新映射連接埠。但是，您不應重新映射負載平衡器端點。有關 StorageGRID 節點的連接埠重新映射資訊，請參閱相關文件：



NOTE: 連接埠重新映射支援已棄用，將在未來的版本中移除。若要移除已重新映射的連接埠，請參閱 link:../maintain/removing-port-remaps.html["移除 StorageGRID 應用裝置上的連接埠重映射"] 或 link:../maintain/removing-port-remaps-on-bare-metal-hosts.html["移除裸機主機上的連接埠重映射"]。

* link:../swnodes/creating-node-configuration-files.html["Red Hat Enterprise Linux 上 StorageGRID 的連接埠重新映射鍵"]
* link:../swnodes/deploying-storagegrid-node-as-virtual-machine.html#vmware-remap-ports["重新映射 VMware 上 StorageGRID 的連接埠"]
* https://docs.netapp.com/us-en/storagegrid-appliances/installconfig/optional-remapping-network-ports-for-appliance.html["選用：重新對應應用裝置的網路連接埠"^]
