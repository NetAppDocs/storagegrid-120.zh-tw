= StorageGRID 的用戶端網路拓撲
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
擁有用戶端網路是選用的。使用用戶端網路可將用戶端網路流量（例如 S3）與網格內部流量分隔，這可讓網格連網更加安全。未設定管理網路時，系統管理流量可由用戶端網路或網格網路處理。

設定用戶端網路時，需要為已設定節點的 eth2 介面設定主機 IP 位址、子網路遮罩和閘道 IP 位址。每個節點的用戶端網路都可以獨立於其他節點的用戶端網路。

如果在安裝期間為節點設定了 Client Network，則安裝完成後，該節點的預設閘道將從 Grid Network 閘道切換至 Client Network 閘道。如果稍後新增 Client Network，節點的預設閘道也會以相同的方式切換。

在此範例中，用戶端網路用於 S3 用戶端請求和管理功能，而網格網路則專用於內部物件管理操作。
