= StorageGRID 中支援的 Amazon S3 Select 作業
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
StorageGRID 支援下列 Amazon S3 Select 子句、資料類型和運算子，適用於 link:select-object-content.html["SelectObjectContent 命令"]。


NOTE: 未列出的項目均不受支援。

如需語法，請參閱 link:select-object-content.html["SelectObjectContent"]。如需 S3 Select 的詳細資訊，請參閱 https://docs.aws.amazon.com/AmazonS3/latest/userguide/selecting-content-from-objects.html["AWS S3 Select 文件"^]。

只有啟用了 S3 Select 的租戶帳戶才能發出 SelectObjectContent 查詢。請參閱link:../admin/manage-s3-select-for-tenant-accounts.html["使用 S3 Select 的注意事項和要求"]。
