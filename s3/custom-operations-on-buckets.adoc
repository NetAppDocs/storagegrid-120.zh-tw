= StorageGRID 中支援的自訂儲存貯體作業
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
StorageGRID 系統支援新增至 S3 REST API 的自訂操作。

下表列出 StorageGRID 支援的自訂操作。

[cols="1a,2a"]
|===
| 操作 | 說明 


 a| 
link:get-bucket-consistency-request.html["GET 儲存貯器一致性"]
 a| 
傳回套用至特定儲存貯體的一致性。



 a| 
link:put-bucket-consistency-request.html["PUT Bucket 一致性"]
 a| 
設定套用至特定儲存貯體的一致性。



 a| 
link:get-bucket-last-access-time-request.html["取得儲存桶上次存取時間"]
 a| 
傳回特定儲存桶是否啟用或停用上次存取時間更新。



 a| 
link:put-bucket-last-access-time-request.html["PUT 儲存貯體最後存取時間"]
 a| 
允許您啟用或停用特定儲存桶的最後存取時間更新。



 a| 
link:delete-bucket-metadata-notification-configuration-request.html["刪除 Bucket 中繼資料通知組態"]
 a| 
刪除與特定儲存桶關聯的中繼資料通知組態 XML。



 a| 
link:get-bucket-metadata-notification-configuration-request.html["取得 Bucket 中繼資料通知組態"]
 a| 
傳回與特定儲存桶關聯的中繼資料通知組態 XML。



 a| 
link:put-bucket-metadata-notification-configuration-request.html["PUT Bucket 中繼資料通知組態"]
 a| 
為儲存桶設定中繼資料通知服務。



 a| 
link:get-storage-usage-request.html["取得儲存使用情況"]
 a| 
顯示帳戶正在使用的總儲存設備量，以及與該帳戶關聯的每個儲存桶的儲存設備量。



 a| 
link:deprecated-put-bucket-request-modifications-for-compliance.html["已棄用：CreateBucket 帶有法規遵循設定"]
 a| 
已棄用且不再支援：您無法再建立啟用法規遵循的新儲存桶。



 a| 
link:deprecated-get-bucket-compliance-request.html["已棄用：GET Bucket 法規遵循"]
 a| 
已棄用但仍受支援：傳回現有舊版 Compliant 儲存桶目前生效的法規遵循設定。



 a| 
link:deprecated-put-bucket-compliance-request.html["已棄用：PUT Bucket 法規遵循"]
 a| 
已棄用但仍受支援：允許您修改現有舊版 Compliant 儲存桶的法規遵循設定。

|===
