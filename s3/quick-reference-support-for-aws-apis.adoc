== 常用的 URI 查詢參數和請求標頭

除非另有說明，否則支援以下常見的 URI 查詢參數：

* `versionId`（物件操作所需）


除非另有說明，否則支援以下常用請求標頭：

* `Authorization`
* `Connection`
* `Content-Length`
* `Content-MD5`
* `Content-Type`
* `Date`
* `Expect`
* `Host`
* `x-amz-date`
