= StorageGRID 中物件擷取交易的稽核訊息
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以透過尋找 S3 API 特定的稽核訊息，在稽核日誌中識別物件擷取交易。

下表並未列出擷取交易期間產生的所有稽核訊息。表中僅包含追蹤擷取交易所需的訊息。



[[s3-retrieval-audit-messages]]
== S3 擷取稽核訊息

[cols="1a,1a,2a,1a,1a"]
|===
| 程式碼 | Name | 說明 | 追蹤 | 請參閱 


 a| 
SGET
 a| 
S3 GET
 a| 
從儲存桶中擷取物件的請求。
 a| 
CBID、S3BK、S3KY
 a| 
link:sget-s3-get.html["SGET：S3 GET"]

|===


[[example-s3-object-retrieval]]
== 範例：S3 物件擷取

當 S3 用戶端從儲存節點（LDR 服務）擷取物件時，會產生一則稽核訊息並儲存至稽核日誌。

請注意，以下範例並未列出事務期間產生的所有稽核訊息。僅列出與 S3 擷取事務 （SGET） 相關的稽核訊息。



[[sget-s3-get]]
=== SGET：S3 GET

當用戶端向 LDR 服務傳送 GetObject 要求時，即會開始擷取物件。該訊息包含要從中擷取物件的 Bucket 以及用於識別物件的 S3 Key。

[listing, subs="specialcharacters,quotes"]
----

如果儲存貯體原則允許，用戶端可以匿名擷取物件，或從不同租戶帳戶所擁有的儲存貯體中擷取物件。稽核訊息包含關於儲存貯體擁有者租戶帳戶的資訊，以便您追蹤這些匿名和跨帳戶要求。

在以下範例訊息中，用戶端針對其未擁有的儲存貯體中儲存的物件傳送 GetObject 請求。SBAI 和 SBAC 的值會記錄儲存貯體擁有者的租戶帳戶 ID 和名稱，這與 S3AI 和 SACC 中記錄的用戶端租戶帳戶 ID 和名稱不同。

[listing, subs="specialcharacters,quotes"]
----

[[example-s3-select-on-an-object]]
== 範例：對物件執行 S3 Select

當 S3 用戶端對物件發出 S3 Select 查詢時，會產生稽核訊息並儲存到稽核日誌。

請注意，並非交易期間產生的所有稽核訊息都會列在以下範例中。僅列出與 S3 Select 交易（SelectObjectContent）相關的稽核訊息。

每個查詢都會產生兩個稽核訊息：一個用於執行 S3 Select 請求的授權（S3SR 欄位設定為「select」），另一個是後續的標準 GET 操作，該操作在處理期間從儲存設備擷取資料。
