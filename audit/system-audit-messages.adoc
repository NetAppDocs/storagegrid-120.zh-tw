= StorageGRID 中系統事件的稽核訊息
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
屬於系統稽核類別的稽核訊息用於與稽核系統本身、網格節點狀態、系統範圍的工作活動（網格工作）和服務備份作業相關的事件。

[cols="1a,2a,1a"]
|===
| 程式碼 | 訊息標題和執行摘要 | 請參閱 


 a| 
ECMC
 a| 
缺少糾刪碼資料片段：表示偵測到缺少的糾刪碼資料片段。
 a| 
link:ecmc-missing-erasure-coded-data-fragment.html["ECMC：缺少的糾刪碼資料片段"]



 a| 
ECOC
 a| 
毀損的銷除編碼資料片段：表示偵測到毀損的銷除編碼資料片段。
 a| 
link:ecoc-corrupt-erasure-coded-data-fragment.html["ECOC：毀損的銷除編碼資料片段"]



 a| 
ETAF
 a| 
安全認證失敗：使用傳輸層安全性協定 (TLS) 的連線嘗試失敗。
 a| 
link:etaf-security-authentication-failed.html["ETAF：安全認證失敗"]



 a| 
GNRG
 a| 
GNDS 註冊：一項服務在 StorageGRID 系統中更新或註冊有關自身的資訊。
 a| 
link:gnrg-gnds-registration.html["GNRG：GNDS 註冊"]



 a| 
GNUR
 a| 
GNDS 登出：某項服務已從 StorageGRID 系統中登出。
 a| 
link:gnur-gnds-unregistration.html["GNUR：GNDS Unregistration"]



 a| 
GTED
 a| 
網格工作已結束：CMN 服務已完成網格工作的處理。
 a| 
link:gted-grid-task-ended.html["GTED：網格工作已結束"]



 a| 
GTST
 a| 
網格工作已啟動：CMN 服務已開始處理網格工作。
 a| 
link:gtst-grid-task-started.html["GTST：Grid Task Started"]



 a| 
GTSU
 a| 
網格工作已提交：已向 CMN 服務提交網格工作。
 a| 
link:gtsu-grid-task-submitted.html["GTSU：網格工作已提交"]



 a| 
LLST
 a| 
位置遺失：當位置遺失時，將產生此稽核訊息。
 a| 
link:llst-location-lost.html["LLST：位置遺失"]



 a| 
OLST
 a| 
物件遺失：無法在 StorageGRID 系統中找到請求的物件。
 a| 
link:olst-system-detected-lost-object.html["OLST：系統偵測到遺失物件"]



 a| 
SADD
 a| 
安全性稽核已停用：稽核訊息記錄已關閉。
 a| 
link:sadd-security-audit-disable.html["SADD：安全稽核停用"]



 a| 
SADE
 a| 
安全性稽核已啟用：稽核訊息記錄已還原。
 a| 
link:sade-security-audit-enable.html["SADE：Security Audit Enable"]



 a| 
SVRF
 a| 
物件存放區驗證失敗：內容區塊驗證檢查失敗。
 a| 
link:svrf-object-store-verify-fail.html["SVRF：物件存放區驗證失敗"]



 a| 
SVRU
 a| 
物件存放區驗證未知：在物件存放區中偵測到意外的物件資料。
 a| 
link:svru-object-store-verify-unknown.html["SVRU：物件存放區驗證未知"]



 a| 
SYSD
 a| 
節點停止：已請求關閉節點。
 a| 
link:sysd-node-stop.html["SYSD：節點停止"]



 a| 
系統
 a| 
節點停止：服務已啟動正常停止。
 a| 
link:syst-node-stopping.html["SYST：節點停止中"]



 a| 
SYSU
 a| 
節點啟動：服務已啟動；訊息中指示了先前關閉的原因。
 a| 
link:sysu-node-start.html["SYSU：節點啟動"]
