= StorageGRID 中物件接收開始的 CBRB 稽核訊息
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在系統正常運作期間，資料在被存取、複寫和保留時，內容區塊會在不同節點之間持續傳輸。當內容區塊從一個節點傳輸至另一個節點時，目的地實體會發出此訊息。

[cols="1a,1a,4a"]
|===
| 程式碼 | 欄位 | 說明 


 a| 
CNID
 a| 
連線識別碼
 a| 
節點間工作階段/連線的唯一識別碼。



 a| 
CBID
 a| 
內容區塊識別碼
 a| 
正在傳輸的內容區塊的唯一識別碼。



 a| 
CTDR
 a| 
傳輸方向
 a| 
指示 CBID 傳輸是推送發起還是提取發起：

PUSH：傳輸操作由傳送實體請求。

PULL：傳輸操作由接收實體請求。



 a| 
CTSR
 a| 
來源實體
 a| 
CBID 傳輸的來源（發送方）節點 ID。



 a| 
CTDS
 a| 
目的地實體
 a| 
CBID 傳輸的目的地（接收者）節點 ID。



 a| 
CTSS
 a| 
起始序列計數
 a| 
表示請求的第一個序號。如果成功，傳輸將從該序號開始。



 a| 
CTES
 a| 
預期結束序列計數
 a| 
表示請求的最後一個序號。如果成功，則在收到此序號後，傳輸即視為完成。



 a| 
RSLT
 a| 
傳輸開始狀態
 a| 
傳輸開始時的狀態：

SUCS：傳輸已成功開始。

|===
此稽核訊息表示已針對單一內容（由其內容區塊識別碼標識）發起節點間資料傳輸作業。此操作請求的資料範圍為「起始序列計數」至「預期結束序列計數」。發送節點和接收節點透過其節點 ID 進行識別。此資訊可用於追蹤系統資料流，並可與儲存設備稽核訊息結合使用，以驗證副本計數。
