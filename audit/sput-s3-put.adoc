= StorageGRID 中 S3 PUT 交易的 SPUT 稽核訊息
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
當 S3 用戶端發出 PUT 交易時，會要求建立新物件或儲存桶，或移除儲存桶/物件子資源。如果交易成功，伺服器會發出此訊息。

[cols="1a,1a,4a"]
|===
| 程式碼 | 欄位 | 說明 


 a| 
CBID
 a| 
內容區塊識別碼
 a| 
所請求內容區塊的唯一識別碼。如果 CBID 未知，則此欄位設為 0。對儲存桶的操作不包含此欄位。



 a| 
CMPS
 a| 
法規遵循設定
 a| 
建立儲存桶時使用的法規遵循設定（如果請求中存在）（截斷為前 1024 個字元）。



 a| 
CNCH
 a| 
一致性控制標頭
 a| 
如果請求中存在 Consistency-Control HTTP 請求標頭，則該請求標頭的值即為 Consistency-Control 的值。



 a| 
CNID
 a| 
連線識別碼
 a| 
TCP/IP 連線的唯一系統識別碼。



 a| 
CSIZ
 a| 
內容大小
 a| 
擷取的物件大小（以位元組為單位）。值區上的作業不包含此欄位。



 a| 
GFID
 a| 
網格聯盟連線 ID
 a| 
與跨網格複寫 PUT 請求關聯的網格同盟連線的連線 ID。僅包含在目的地網格的稽核日誌中。



 a| 
GFSA
 a| 
網格聯盟來源帳戶 ID
 a| 
來源網格上租戶的帳戶 ID，用於跨網格複寫 PUT 請求。僅包含在目的地網格的稽核日誌中。



 a| 
HTRH
 a| 
HTTP 請求標頭
 a| 
在組態期間選擇的已記錄 HTTP 請求標頭名稱和值清單。

 `X-Forwarded-For`如果請求中存在該欄位，且 `X-Forwarded-For`值與請求發送方 IP 位址（SAIP 稽核欄位）不同，則會自動包含該欄位。

`x-amz-bypass-governance-retention`如果請求中存在該參數，則會自動包含在內。



 a| 
LKEN
 a| 
物件鎖定已啟用
 a| 
請求標頭的值 `x-amz-bucket-object-lock-enabled`（如果存在於請求中）。



 a| 
LKLH
 a| 
物件鎖定法定保留
 a| 
請求標頭的值 `x-amz-object-lock-legal-hold`（如果存在於 PutObject 請求中）。



 a| 
LKMD
 a| 
物件鎖定保留模式
 a| 
請求標頭 `x-amz-object-lock-mode`的值（如果存在於 PutObject 請求中）。



 a| 
LKRU
 a| 
物件鎖定保留至日期
 a| 
要求標頭的值 `x-amz-object-lock-retain-until-date`，如果存在於 PutObject 要求中。值限制在物件內嵌日期的 100 年內。



 a| 
MTME
 a| 
最後修改時間
 a| 
Unix 時間戳記，以微秒為單位，表示物件上次修改的時間。



 a| 
RSLT
 a| 
結果代碼
 a| 
PUT 交易的結果。結果始終為：

SUCS：成功



 a| 
S3AI
 a| 
S3 租戶帳戶 ID （請求傳送者）
 a| 
發送請求的使用者租戶帳戶 ID。空值表示匿名存取。



 a| 
S3AK
 a| 
S3 存取金鑰 ID（請求傳送者）
 a| 
傳送請求的使用者的雜湊 S3 存取金鑰 ID。空值表示匿名存取。



 a| 
S3BK
 a| 
S3 Bucket
 a| 
S3 儲存桶名稱。



 a| 
S3KY
 a| 
S3 金鑰
 a| 
S3 金鑰名稱，不包含儲存桶名稱。對儲存桶的操作不涉及此欄位。



 a| 
S3SR
 a| 
S3 子資源
 a| 
如果適用，則為正在操作的儲存貯體或物件子資源。



 a| 
SACC
 a| 
S3 租戶帳戶名稱（要求傳送者）
 a| 
傳送請求之使用者的租戶帳戶名稱。匿名請求時為空白。



 a| 
SAIP
 a| 
IP 位址（請求傳送方）
 a| 
發出請求的用戶端應用程式的 IP 位址。



 a| 
SBAC
 a| 
S3 租戶帳戶名稱（儲存桶擁有者）
 a| 
儲存桶擁有者的租戶帳戶名稱。用於識別跨帳戶或匿名存取。



 a| 
SBAI
 a| 
S3 租戶帳戶 ID （儲存桶擁有者）
 a| 
目標儲存桶擁有者的租戶帳戶 ID。用於識別跨帳戶或匿名存取。



 a| 
SRCF
 a| 
子資源組態
 a| 
新的子資源組態（截取前 1024 個字元）。



 a| 
SUSR
 a| 
S3 使用者 URN（請求傳送方）
 a| 
租戶帳戶 ID 和發出請求的使用者名稱。使用者可以是本機使用者或 LDAP 使用者。例如： `urn:sgws:identity::03393893651506583485:root`

匿名請求為空白。



 a| 
時間
 a| 
時間
 a| 
處理該請求的總耗時（以微秒為單位）。



 a| 
TLIP
 a| 
可信任負載平衡器 IP 位址
 a| 
如果請求是由受信任的第 7 層負載平衡器路由，則為負載平衡器的 IP 位址。



 a| 
ULID
 a| 
上傳 ID
 a| 
僅包含在 CompleteMultipartUpload 操作的 SPUT 訊息中。表示所有部件均已上傳並組裝完成。



 a| 
UUID
 a| 
通用唯一識別符
 a| 
StorageGRID 系統中物件的識別碼。



 a| 
VSID
 a| 
版本 ID
 a| 
在版本化儲存桶中建立的新物件的版本 ID。對非版本化儲存桶及其中的物件執行的操作不包含此欄位。



 a| 
VSST
 a| 
版本控制狀態
 a| 
儲存桶的新版本控制狀態。有兩種狀態：「已啟用」或「已暫停」。對物件執行的操作不包含此欄位。

|===
