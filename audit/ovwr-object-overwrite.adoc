= StorageGRID 中物件覆寫的 OVWR 稽核訊息
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
當外部（用戶端請求的）操作導致一個物件被另一個物件覆蓋時，會產生此訊息。

[cols="1a,1a,4a"]
|===
| 程式碼 | 欄位 | 說明 


 a| 
CBID
 a| 
內容區塊識別碼（新增）
 a| 
新物件的 CBID。



 a| 
CSIZ
 a| 
先前物件大小
 a| 
被覆寫物件的大小（以位元組為單位）。



 a| 
OCBD
 a| 
內容區塊識別碼（上一個）
 a| 
前一個物件的 CBID。



 a| 
UUID
 a| 
通用唯一識別碼（新）
 a| 
StorageGRID 系統中新物件的識別碼。



 a| 
OUID
 a| 
通用唯一識別碼（前身）
 a| 
StorageGRID 系統中前一個物件的識別碼。



 a| 
路徑
 a| 
S3 物件路徑
 a| 
先前物件和新物件都使用的 S3 物件路徑



 a| 
RSLT
 a| 
結果代碼
 a| 
物件覆寫交易的結果。結果始終為：

SUCS：成功



 a| 
SGRP
 a| 
網站（組）
 a| 
如果存在，則被覆寫的物件會在指定的站台刪除，但該站台不是擷取被覆寫物件的站台。

|===
