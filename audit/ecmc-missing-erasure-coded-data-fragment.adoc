= StorageGRID 中遺失銷毀編碼資料的 ECMC 稽核訊息
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
此稽核訊息顯示系統偵測到缺少的糾刪碼資料片段。

[cols="1a,1a,4a"]
|===
| 程式碼 | 欄位 | 說明 


 a| 
VCMC
 a| 
VCS ID
 a| 
包含缺失資料塊的版本控制系統的名稱。



 a| 
MCID
 a| 
區塊 ID
 a| 
缺少的銷毀編碼片段識別碼。



 a| 
RSLT
 a| 
結果
 a| 
此欄位的值為 'NONE'。RSLT 是必填訊息欄位，但與此特定訊息無關。使用 'NONE' 而非 'SUCS'，是為了避免此訊息被過濾。

|===
