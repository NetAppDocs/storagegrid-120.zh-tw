= StorageGRID 中 GNDS 取消註冊的 GNUR 稽核訊息
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
當服務從 StorageGRID 系統取消登錄自身相關資訊時，CMN 服務會產生此稽核訊息。

[cols="1a,1a,4a"]
|===
| 程式碼 | 欄位 | 說明 


 a| 
RSLT
 a| 
結果
 a| 
更新請求的結果：

* SUCS：成功
* SUNV：服務無法使用
* GERR：其他故障




 a| 
GNID
 a| 
節點 ID
 a| 
發起更新請求的服務節點 ID。

|===
