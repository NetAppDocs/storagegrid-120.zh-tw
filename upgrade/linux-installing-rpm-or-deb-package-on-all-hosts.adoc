= 在所有 Linux 主機上下載並安裝 RPM 或 DEB 套件以供 StorageGRID 使用
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果任何 StorageGRID 節點部署在 Linux 主機上，請在開始升級之前，在每個主機上下載並安裝額外的 RPM 或 DEB 套件。



[[download-upgrade-linux-and-hotfix-files]]
== 下載升級、Linux 和 Hotfix 檔案

當您從 Grid Manager 執行 StorageGRID 升級時，系統會提示您下載升級歸檔和任何所需的 Hotfix 作為第一步。但是，如果您需要下載檔案來升級 Linux 主機，可以提前下載所有必要的檔案，以節省時間。

.步驟
. 前往  https://mysupport.netapp.com/site/products/all/details/storagegrid/downloads-tab["NetApp 下載：StorageGRID"^]。
. 選擇下載最新版本的按鈕，或從下拉式選單中選擇其他版本，然後選擇 *Go*。
+
StorageGRID 軟體版本採用以下格式：11._x.y_。StorageGRID Hotfix 採用以下格式：11._x.y.z_。

. 使用您 NetApp 帳戶的用戶名和密碼登入。
. 如果出現警告/MustRead通知，請記下 Hotfix 編號，並勾選核取方塊。
. 閱讀終端使用者授權合約（EULA），選取核取方塊，然後選取 *Accept & Continue*。
+
您選擇的版本的下載頁面隨即顯示。此頁面包含三欄。

. 從第二欄（*升級 StorageGRID*）下載兩個檔案：
+
** 最新版本的升級歸檔（這是標示為「VMware、SG1000 或 SG100 主要管理節點」部分中的檔案）。雖然在執行升級之前不需要此檔案，但現在下載可以節省時間。
** RPM 或 DEB 歸檔，格式為 `.tgz`或 `.zip`。如果服務筆記型電腦執行的是 Windows，請選擇 `.zip`檔案。
+
*** RHEL +
`StorageGRID-Webscale-_version_-RPM-_uniqueID_.zip` +
`StorageGRID-Webscale-_version_-RPM-_uniqueID_.tgz`
*** Ubuntu 或 Debian +
`StorageGRID-Webscale-_version_-DEB-_uniqueID_.zip` +
`StorageGRID-Webscale-_version_-DEB-_uniqueID_.tgz`




. 如果您因為需要安裝 Hotfix 而需要同意警告/MustRead 通知，請下載該 Hotfix：
+
.. 返回 https://mysupport.netapp.com/site/products/all/details/storagegrid/downloads-tab["NetApp 下載：StorageGRID"^]。
.. 從下拉式選單中選擇 Hotfix 編號。
.. 再次同意警告通知和最終用戶許可協議。
.. 下載並儲存此 Hotfix 及其 README。
+
開始升級時，StorageGRID 升級頁面會提示您上傳 Hotfix 檔案。



. 在 Linux 節點上，程式碼簽署驗證是手動的。您也可以選擇驗證安裝歸檔：
+
.. 下載 StorageGRID 程式碼簽署驗證套件。此套件的檔案名稱格式為 `StorageGRID_<version-number>_Code_Signature_Verification_Package.tar.gz`，其中 `<version-number>`為 StorageGRID 軟體版本。
.. 請依照以下步驟操作link:../swnodes/download-files-verify.html["手動驗證安裝檔案"]。






[[install-archive-on-all-linux-hosts]]
== 在所有 Linux 主機上安裝歸檔

在升級 StorageGRID 軟體之前，請執行下列步驟。

.步驟
. 從安裝檔案中擷取 RPM 或 DEB 軟體包。
. 在所有 Linux 主機上安裝 RPM 或 DEB 軟體套件。
+
請參閱在 Linux 上安裝 StorageGRID 主機服務的步驟，請見 link:../swnodes/installing-storagegrid-webscale-host-services.html["安裝 StorageGRID 主機服務"]。

+
新套件將作為附加套件安裝。





[[remove-installation-archives-for-previous-versions]]
== 移除先前版本的安裝封存檔

為了釋放 Linux 主機上的空間，您可以移除不再需要的舊版 StorageGRID 安裝封存檔。

.步驟
. 移除舊的 StorageGRID 安裝封存檔。
