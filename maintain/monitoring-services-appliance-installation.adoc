= 監控 StorageGRID 服務應用裝置安裝
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
StorageGRID 應用裝置安裝程式會提供狀態，直到安裝完成為止。軟體安裝完成後，應用裝置會重新開機。

.步驟
. 若要監控安裝進度，請點選選單列中的「Monitor Installation」。
+
「Monitor Installation」頁面顯示安裝進度。

+
藍色狀態列表示目前正在進行的工作。綠色狀態列表示已成功完成的工作。

+

NOTE: 安裝程式會確保不會重新執行先前安裝中已完成的工作。如果您正在重新執行安裝，任何不需要重新執行的工作都會顯示綠色狀態列，且狀態為「已跳過」。

. 檢閱前兩個安裝階段的進度。
+
** *1.設定儲存設備*
+
在此階段，安裝程式會清除磁碟機上的所有現有組態，並設定主機設定。

** *2.安裝作業系統*
+
在此階段，安裝程式會將 StorageGRID 的基本作業系統映像從主要管理節點複製到應用裝置，或從主要管理節點的安裝套件安裝基本作業系統。



. 持續監控安裝進度，直到出現以下情況之一：
+
** 對於應用裝置 Gateway 節點或非主要應用裝置管理節點，*Install StorageGRID* 階段會暫停，嵌入式主控台上會出現一則訊息，提示您使用 Grid Manager 在管理節點上核准此節點。
** 對於應用裝置主管理節點，會出現第五階段（載入 StorageGRID 安裝程式）。如果第五階段持續超過 10 分鐘，請手動重新整理頁面。


. 前往您正在恢復的應用裝置網格節點類型的恢復程序的下一步。
