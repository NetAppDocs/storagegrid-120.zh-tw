= StorageGRID Hotfix 程序
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
${post_edited_translations.segment}

StorageGRID Hotfix 包含在功能或修補程式版本之外提供的軟體變更。相同的變更將包含在未來的版本中。此外，每個 Hotfix 版本都包含該功能或修補程式版本中所有先前 Hotfix 的彙總。



[[considerations-for-applying-a-hotfix]]
== ${post_edited_translations.segment}

當其他維護程序正在運作時，您無法套用 StorageGRID Hotfix。例如，在退役、擴充或恢復程序執行時，您無法套用 Hotfix。


NOTE: 如果節點或站台退役程序已暫停，您可以安全地套用 Hotfix。此外，您可能可以在 StorageGRID 升級程序的最後階段套用 Hotfix。請參閱升級 StorageGRID 軟體的說明以取得詳細資訊。

在 Grid Manager 中上傳 Hotfix 之後，系統會自動將 Hotfix 套用至主要 Admin Node。然後，您可以核准將 Hotfix 套用至 StorageGRID 系統中的其餘節點。

如果無法將 Hotfix 套用至一或多個節點，失敗的原因會顯示在 Hotfix 進度表的「詳細資料」欄中。您必須解決導致失敗的任何問題，然後重試整個程序。在後續的套用中，將會跳過先前已成功套用 Hotfix 的節點。您可以安全地根據需要重試 Hotfix 程序多次，直到所有節點都已更新為止。必須在所有網格節點上成功安裝 Hotfix，才能完成套用。

雖然網格節點會更新到新的 Hotfix 版本，但 Hotfix 中的實際變更可能只會影響特定類型節點上的特定服務。例如，Hotfix 可能只會影響儲存節點上的 LDR 服務。



[[how-hotfixes-are-applied-for-recovery-and-expansion]]
== ${post_edited_translations.segment}

將 Hotfix 套用至網格後，主要管理節點會自動將相同的 Hotfix 版本安裝到透過恢復作業還原或在擴充中新增的任何節點。

但是，如果您需要恢復主管理節點，則必須手動安裝正確的 StorageGRID 版本，然後套用 Hotfix。主管理節點的最終 StorageGRID 版本必須與網格中其他節點的版本相符。
