= 從主 StorageGRID 管理節點故障中恢復
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您必須完成一組特定的工作，才能從主要 Admin 節點故障中恢復。主要 Admin 節點裝載了網格的 Configuration Management Node (CMN) 服務。


CAUTION: 您必須及時修復或更換故障的主要管理節點，否則可能無法執行某些維護程序。
