= 下載並擷取 StorageGRID 安裝檔案
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在恢復 StorageGRID 節點之前，您必須下載軟體並擷取檔案。

您必須使用目前在網格上執行的 StorageGRID 版本。

.步驟
. 確定目前安裝的軟體版本。從 Grid Manager 的頂端，選取說明圖示，然後選取 *關於*。
. 前往 NetApp StorageGRID 的下載頁面。
+
https://mysupport.netapp.com/site/products/all/details/storagegrid/downloads-tab["NetApp 下載：StorageGRID"^]

. 選擇目前在網格上執行的 StorageGRID 版本。
+
StorageGRID 軟體版本格式為：11.x.y。

. 使用您 NetApp 帳戶的用戶名和密碼登入。
. 閱讀終端使用者授權合約，選取核取方塊，然後選取 *Accept & Continue*。
. 在下載頁面的 *Install StorageGRID* 欄位中，選取適用於您平台的  `.tgz` 或  `.zip` 檔案。
+
安裝歸檔檔案中顯示的版本必須與目前已安裝軟體的版本一致。

+
如果您使用的是 Windows 系統，請使用  `.zip` 檔案。

+
[cols="1a,2a"]
|===
| 平台 | 安裝歸檔 


 a| 
RHEL
| `StorageGRID-Webscale-_version_-RPM-_uniqueID_.zip` 
`StorageGRID-Webscale-_version_-RPM-_uniqueID_.tgz` 


 a| 
Ubuntu、Debian 或應用裝置
| `StorageGRID-Webscale-_version_-DEB-_uniqueID_.zip` 
`StorageGRID-Webscale-_version_-DEB-_uniqueID_.tgz` 


 a| 
VMware
| `StorageGRID-Webscale-_version_-VMware-_uniqueID_.zip` 
`StorageGRID-Webscale-_version_-VMware-_uniqueID_.tgz` 
|===
. 下載並擷取歸檔檔案。
. 根據您的平台以及您需要恢復的網格節點，請按照適用於您平台的步驟選擇所需的檔案。
+
每個平台步驟中列出的路徑，均相對於歸檔檔案所安裝的頂層目錄。

. 如果您要恢復 link:../swnodes/index.html["軟體型節點"]，請選擇適當的檔案：
+

====
.RHEL
--
[cols="1a,1a"]
|===
| 路徑和檔案名稱 | 說明 


| ./rpms/README  a| 
描述 StorageGRID 下載檔案中所包含的所有檔案的文字檔案。



| ./rpms/NLF000000.txt  a| 
免費授權，不提供任何產品支援服務。



| ./rpms/StorageGRID-Webscale-Images-_version_-SHA.rpm  a| 
用於在 RHEL 主機上安裝 StorageGRID 節點映像的 RPM 套件。



| ./rpms/StorageGRID-Webscale-Service-_version_-SHA.rpm  a| 
用於在 RHEL 主機上安裝 StorageGRID 主機服務的 RPM 套件。



| 部署指令碼工具 | 說明 


| ./rpms/configure-storagegrid.py  a| 
用於自動化 StorageGRID 系統組態的 Python 指令碼。



| ./rpms/configure-sga.py  a| 
用於自動化 StorageGRID 應用裝置組態的 Python 指令碼。



| ./rpms/configure-storagegrid.sample.json  a| 
搭配  `configure-storagegrid.py` 指令碼使用的範例組態檔案。



| ./rpms/storagegrid-ssoauth.py  a| 
這是一個範例 Python 指令碼，可用於在啟用單一登入的情況下登入 Grid Management API。您也可以使用此指令碼進行 Ping Federate 整合。



| ./rpms/configure-storagegrid.blank.json  a| 
一個用於搭配  `configure-storagegrid.py` 指令碼使用的空白組態檔案。



| ./rpms/extras/ansible  a| 
用於為 StorageGRID Container 部署設定 RHEL 主機的範例 Ansible 角色與 Playbook。您可以根據需要自訂角色或 Playbook。



| ./rpms/storagegrid-ssoauth-azure.py  a| 
這是一個範例 Python 指令碼，當使用 Active Directory 或 Ping Federate 啟用單一登入 （SSO） 時，您可以使用該指令碼登入 Grid Management API。



| ./rpms/storagegrid-ssoauth-azure.js  a| 
由隨附的  `storagegrid-ssoauth-azure.py` Python 指令碼所呼叫的輔助指令碼，用於與 Azure 進行 SSO 互動。



| ./rpms/extras/api-schemas  a| 
StorageGRID 的 API 架構。

*注意*：在執行升級之前，如果您沒有用於升級相容性測試的非生產性 StorageGRID 環境，可以使用這些架構來確認您編寫的任何使用 StorageGRID 管理 API 的程式碼是否與新的 StorageGRID 版本相容。
