= 在系統磁碟機完好的情況下，從 StorageGRID 儲存磁碟區故障中恢復
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您必須完成一系列工作，以恢復軟體型儲存節點，其中該儲存節點上的一或多個儲存 Volume 已故障，但系統磁碟機完好無損。如果只有儲存 Volume 故障，則該儲存節點對於 StorageGRID 系統仍為可用。


NOTE: 此恢復程序僅適用於軟體型儲存節點。如果應用裝置儲存節點上的儲存 Volume 發生故障，請改用應用裝置恢復程序：link:recovering-storagegrid-appliance-storage-node.html["恢復應用裝置儲存節點"]。
