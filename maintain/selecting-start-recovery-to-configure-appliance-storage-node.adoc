= 選擇 Start Recovery 以配置 StorageGRID 應用裝置儲存節點
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您必須在 Grid Manager 中選擇「開始恢復」，才能將應用裝置儲存節點設定為故障節點的替代品。

.開始之前
* 您已使用 link:../admin/web-browser-requirements.html["支援的網頁瀏覽器"] 登入 Grid Manager。
* 您有link:../admin/admin-group-permissions.html["維護或 Root 存取權限"]。
* 您擁有佈建密碼。
* 您已部署恢復應用裝置儲存節點。
* 您擁有所有銷毀編碼資料修復工作的開始日期。


.步驟
. 從 Grid Manager 中，選擇 *Maintenance* > *Tasks* > *Recovery*。
. 在「待恢復節點」清單中選擇要恢復的網格節點。
+
節點發生故障後會出現在清單中，但只有在節點重新安裝並準備好恢復後才能選擇該節點。

. 請輸入*佈建密碼*。
. 點選 *Start Recovery*。
+
image:4b_select_recovery_node.png["螢幕截圖顯示「維護 > 恢復」頁面"]

. 在「正在恢復的網格節點」表中監控恢復進度。
+
當網格節點達到「等待手動步驟」階段時，請前往下一個主題並執行手動步驟以重新掛載和重新格式化應用裝置儲存設備 Volume。

+
image:recovery_reset_button.gif["顯示階段等待手動步驟的螢幕截圖"]

+

NOTE: 在恢復過程中的任何階段，您都可以按一下 *Reset* 以開始新的恢復。此時會出現一個對話框，提示若您重設程序，節點將處於不確定狀態。

+
image:recovery_reset_warning.gif["快照顯示重設恢復警告對話框"]

+
如果要在重置程序後重試恢復，則必須透過在節點上執行 `sgareinstall`，將應用裝置節點還原至預安裝狀態。
