= StorageGRID 管理或閘道節點取消委任考量
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
檢閱退役管理節點或閘道節點的相關注意事項。



[[considerations-for-admin-node]]
== 管理節點注意事項

* 您無法退役主管理節點。
* 如果管理節點的某個網路介面屬於高可用度 （HA） 群組，則無法將其退役。必須先將該網路介面從 HA 群組中移除。請參閱相關說明 link:../admin/managing-high-availability-groups.html["管理 HA 群組"]。
* 如有需要，您可以在退役管理節點時安全地變更 ILM 原則。
* 如果您退役管理節點，且您的 StorageGRID 系統已啟用單一登入 （SSO），則必須記住從 Active Directory Federation Services （AD FS） 中移除該節點的信賴方信任。
* 如果使用 link:../admin/grid-federation-overview.html["網格聯盟"]，請確保要退役的節點的 IP 位址未指定用於網格聯邦連線。
* 當您退役已中斷連線的管理節點時，您將遺失該節點的稽核日誌；但是，這些日誌也應該存在於主要管理節點上。




[[considerations-for-gateway-node]]
== 閘道節點的相關考量因素

* 如果閘道節點的某個網路介面屬於高可用度 （HA） 群組，則無法退役。您必須先將該網路介面從 HA 群組中移除。請參閱相關說明 link:../admin/managing-high-availability-groups.html["管理 HA 群組"]。
* 如有需要，您可以在退役閘道節點時安全地變更 ILM 原則。
* 如果使用 link:../admin/grid-federation-overview.html["網格聯盟"]，請確保要退役的節點的 IP 位址未指定用於網格聯邦連線。
* 您可以在 Gateway Node 斷線時安全地將其退役。
