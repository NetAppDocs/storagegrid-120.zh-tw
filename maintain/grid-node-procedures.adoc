= StorageGRID 節點維護程序
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可能需要執行與特定網格節點或節點服務相關的維護程序。

移動 ADC:: link:../maintain/understanding-adc-service-quorum.html["ADC 服務"] 位於某些儲存節點上。在某些退役和節點轉換的情況下，您需要將 ADC 服務移動到同一站台上的另一個儲存節點。
將儲存節點轉換為僅資料節點:: 您可以將不包含 ADC 服務的儲存節點轉換為僅儲存資料的儲存節點。
節點重新開機、關機和電源:: 您可以使用這些程序來重新開機一個或多個節點、關閉並重新啟動節點，或關閉節點電源並重新開啟節點電源。
連接埠重映射:: 例如，如果您想要使用先前已重新對應的連接埠來設定負載平衡器端點，則可以使用連接埠重新對應程序從節點移除連接埠重新對應。
Server Manager:: Server Manager 在每個網格節點上執行，以監督服務的啟動與停止，並確保服務正常地參加與離開 StorageGRID 系統。Server Manager 也會監控每個網格節點上的服務，並將自動嘗試重新啟動任何報告故障的服務。
+
--
要執行 Server Manager 程序，通常需要存取節點的命令列。


CAUTION: 只有在技術支援人員指示的情況下，您才應該存取 Server Manager。
