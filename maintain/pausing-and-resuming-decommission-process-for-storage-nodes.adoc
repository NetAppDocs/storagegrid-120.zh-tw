= 暫停和恢復 StorageGRID 儲存節點的停用流程
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果您需要執行第二個維護程序，可以在特定階段暫停 Storage Node 的退役程序。在另一個程序完成後，您可以恢復退役。


NOTE: 只有在達到 ILM 評估或糾刪碼資料退役階段時，才會啟用 *Pause* 按鈕；然而，ILM 評估（資料移轉）將繼續在背景執行。

.開始之前
* 您已使用 link:../admin/web-browser-requirements.html["支援的網頁瀏覽器"] 登入 Grid Manager。
* 您有link:../admin/admin-group-permissions.html["維護或 Root 存取權限"]。


.步驟
. 選擇 *Maintenance* > *Tasks* > *Decommission*。
+
顯示「退役」頁面。

. 選擇 *Decommission Nodes*。
+
此時會出現 Decommission Nodes 頁面。當退役程序達到以下任一階段時，系統便會啟用 *Pause* 按鈕。

+
** 評估 ILM
** 退役抹除編碼資料


. 選擇 *Pause* 以暫停程序。
+
目前階段已暫停，*Resume* 按鈕已啟用。

+
image:decommission_nodes_procedure_paused.png["節點退役程序暫停"]

. 其他維護程序完成後，選擇 *Resume* 以繼續進行退役。
