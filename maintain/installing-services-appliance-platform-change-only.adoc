= 安裝 StorageGRID 服務應用裝置（僅限平台變更）
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
當您要恢復託管在 VMware 或 Linux 主機上的故障網格節點，並使用服務應用裝置作為替換節點時，必須先使用與故障節點相同的節點名稱（系統名稱）安裝新的應用裝置硬體。

.開始之前
您擁有以下關於故障節點的資訊：

* *節點名稱*：您必須使用與故障節點相同的節點名稱來安裝服務應用裝置。節點名稱即主機名稱（系統名稱）。
* ${post_edited_translations.segment}


.關於此任務
${post_edited_translations.segment}

.步驟
. 請依照指示安裝新的服務應用裝置。參見 https://docs.netapp.com/us-en/storagegrid-appliances/installconfig/index.html["硬體安裝快速入門"^]。
. ${post_edited_translations.segment}
