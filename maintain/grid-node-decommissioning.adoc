= StorageGRID 網格節點汰除
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以使用節點退役流程移除一個或多個網站上的一個或多個網格節點。您無法退役主管理節點。



[[when-to-decommission-a-node]]
== ${post_edited_translations.segment}

${post_edited_translations.segment}

* 您在擴充功能中新增了一個較大的儲存節點，現在想要移除一個或多個較小的儲存節點，同時保留物件。
+

TIP: 如果您想用新應用裝置取代舊應用裝置，請考慮 https://docs.netapp.com/us-en/storagegrid-appliances/commonhardware/how-appliance-node-cloning-works.html["${post_edited_translations.segment}"^]而非在擴充過程中新增應用裝置，然後再退役舊應用裝置。

* 您需要的總儲存設備更少。
