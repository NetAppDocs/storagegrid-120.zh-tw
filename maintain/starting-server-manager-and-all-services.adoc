= 啟動 StorageGRID Server Manager 和所有服務
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可能需要啟動 Server Manager，它也會啟動網格節點上的所有服務。

.開始之前
您擁有  `Passwords.txt` 檔案。

.關於此任務
在已執行 Server Manager 的網格節點上啟動 Server Manager，會導致 Server Manager 和網格節點上的所有服務重新啟動。

.步驟
. 登入網格節點：
+
.. 請輸入以下命令： `ssh admin@_grid_node_IP_`
.. 請輸入 `Passwords.txt`檔案中列出的密碼。
.. 輸入以下命令以切換至根目錄： `su -`
.. 請輸入 `Passwords.txt`檔案中列出的密碼。


+
當您以根目錄身分登入時，提示符號會從 `$`變為 `#`。

. 啟動 Server Manager: `service servermanager start`
. 登出命令 shell： `exit`
