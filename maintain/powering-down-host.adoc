= 關閉 StorageGRID 主機
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在關閉主機電源之前，必須停止該主機上所有網格節點的服務。

.步驟
. 登入網格節點：
+
.. 請輸入以下命令： `ssh admin@_grid_node_IP_`
.. 請輸入 `Passwords.txt`檔案中列出的密碼。
.. 輸入以下命令以切換至根目錄： `su -`
.. 請輸入 `Passwords.txt`檔案中列出的密碼。


+
當您以根目錄身分登入時，提示符號會從 `$`變為 `#`。

. 停止節點上運行的所有服務： `service servermanager stop`
+
服務關閉可能需要長達 15 分鐘的時間，您可能需要遠端登入系統來監控關閉過程。

. 對主機上的每個節點重複步驟 1 和 2。
. 如果您使用的是 Linux 主機：
+
.. 登入主機作業系統。
.. 停止節點： `storagegrid node stop`
.. 關閉主機作業系統。


. 如果節點在 VMware 虛擬機器上執行，或是應用裝置節點，請發出 shutdown 命令： `shutdown -h now`
+
無論  `service servermanager stop` 命令的結果如何，請執行此步驟。

+

NOTE: 在應用裝置節點上下達  `shutdown -h now` 命令之後，您必須將應用裝置關閉電源並重新開啟，以重新啟動節點。

+
對於該應用裝置，此命令會關閉控制器，但應用裝置仍處於通電狀態。您必須完成下一步操作。

. 如果要關閉應用裝置節點，請按照您的應用裝置的步驟操作。
+
[role="tabbed-block"]
====
.SG6160
--
.. 關閉 SG6100-CN 儲存控制器的電源。
.. 等待 SG6100-CN 儲存控制器上的藍色電源 LED 熄滅。


--
.SGF6112
--
.. 關閉應用裝置的電源。
.. 等待藍色電源指示燈熄滅。


--
.SG6000
--
.. 等待儲存控制器背面的綠色快取作用中 LED 熄滅。
+
當快取資料需要寫入磁碟機時，此 LED 就會亮起。您必須等待此 LED 熄滅，然後才能關閉電源。

.. 關閉應用裝置的電源，並等待藍色電源指示燈熄滅。


--
.SG5800
--
.. 等待儲存控制器背面的綠色快取作用中 LED 熄滅。
+
當快取資料需要寫入磁碟機時，此 LED 就會亮起。您必須等待此 LED 熄滅，然後才能關閉電源。

.. 從 SANtricity System Manager 的首頁，選擇「檢視正在進行的動作」。
.. 請確認所有操作均已完成，然後再進行下一步。
.. 關閉控制器機櫃的兩個電源開關，並等待控制器機櫃的所有 LED 指示燈熄滅。


--
.SG5700
--
.. 等待儲存控制器背面的綠色快取作用中 LED 熄滅。
+
當快取資料需要寫入磁碟機時，此 LED 就會亮起。您必須等待此 LED 熄滅，然後才能關閉電源。

.. 關閉應用裝置的電源，並等待所有 LED 和七段數位管顯示活動停止。


--
.SG110 或 SG1100
--
.. 關閉應用裝置的電源。
.. 等待藍色電源指示燈熄滅。


--
.SG100 或 SG1000
--
.. 關閉應用裝置的電源。
.. 等待藍色電源指示燈熄滅。


--
====
. 登出命令 shell： `exit`
