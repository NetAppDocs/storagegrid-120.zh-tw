:allow-uri-read:

:imagesdir: ../media/


[role="lead"]
${post_edited_translations.segment}

.開始之前
您已使用 link:../admin/web-browser-requirements.html["支援的網頁瀏覽器"] 登入 Grid Manager。

.關於此任務
如果此 StorageGRID 系統的軟體授權發生問題，儀表板上的「健全狀況」狀態卡會包含「授權」狀態圖示和 *License* 連結。該數字表示與授權相關的問題數量。

image:dashboard_health_panel_license_status.png["${post_edited_translations.segment}"]
