= StorageGRID 中的租戶帳戶
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
租戶帳戶可讓您使用 Simple Storage Service （S3） REST API 在 StorageGRID 系統中儲存和擷取物件。


TIP: 此版本的說明文件網站已移除 Swift 詳細資訊。請參閱 https://docs.netapp.com/us-en/storagegrid-118/admin/managing-tenants.html["StorageGRID 11.8：管理租戶"^]。

身為網格系統管理員，您可以建立和管理 S3 用戶端用於儲存和擷取物件的租戶帳戶。

每個租戶帳戶都有聯合群組或本機群組、使用者、S3 儲存桶和物件。

租戶帳戶可用於依不同實體隔離儲存的物件。例如，多個租戶帳戶可用於下列任一使用案例：

* *企業使用案例：* 如果您在企業應用程式中管理 StorageGRID 系統，您可能需要根據組織中的不同部門對網格的物件儲存進行隔離。在這種情況下，您可以為行銷部、客戶支援部、人力資源部等建立租戶帳戶。
+

NOTE: 如果您使用 S3 用戶端協定，可以使用 S3 儲存貯體和儲存貯體原則來隔離企業中各部門之間的物件。您不需要使用租戶帳戶。如需詳細資訊，請參閱實作 link:../s3/use-access-policies.html["S3 儲存桶和儲存桶原則"] 的說明。

* *服務供應商使用案例：* 如果您以服務供應商形式管理 StorageGRID 系統，您可以根據租用網格儲存設備的不同實體對網格的物件儲存進行隔離。在這種情況下，您需要為 A 公司、B 公司、C 公司等建立租戶帳戶。


如需詳細資訊，請參閱 link:../tenant/index.html["使用租戶帳戶"]。



[[how-do-i-create-a-tenant-account]]
== 如何建立租戶帳戶？

使用 Grid 管理程式建立租戶帳戶。建立租戶帳戶時，您需要指定以下資訊：

* 基本資訊包括租戶名稱、用戶端類型（S3）和選用的儲存設備配額。
* 租戶帳戶的權限，例如租戶帳戶是否可以使用 S3 平台服務、設定自己的身分來源、使用 S3 Select 或使用網格聯盟連線。
* 根據 StorageGRID 系統是否使用本機群組和使用者、身分聯盟或單一登入 （SSO），確定租戶的初始 root 存取權。


此外，如果 S3 租戶帳戶需要符合法規要求，您可以為 StorageGRID 系統啟用 S3 物件鎖定設定。啟用 S3 物件鎖定後，所有 S3 租戶帳戶都可以建立和管理符合法規的儲存桶。



[[what-is-tenant-manager-used-for]]
== Tenant Manager 是用來做什麼的？

建立租戶帳戶後，租戶使用者可以登入 Tenant Manager 執行下列工作：

* 設定身分識別聯盟（除非身分識別來源與網格共享）
* 管理群組和使用者
* 使用網格聯合進行帳戶 Clone 和跨網格複寫
* 管理 S3 存取金鑰
* 建立和管理 S3 儲存桶
* 使用 S3 平台服務
* 使用 S3 Select
* 監控儲存設備使用情況



TIP: 雖然 S3 租戶用戶可以使用 Tenant Manager 建立和管理 S3 存取金鑰和儲存桶，但他們必須使用 S3 用戶端應用程式來擷取和管理物件。如需詳細資訊，請參閱 link:../s3/index.html["使用 S3 REST API"]。
