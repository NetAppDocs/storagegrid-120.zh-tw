= 刪除 StorageGRID 租用戶帳戶
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果您想要永久移除租戶對系統的存取，則可以刪除租戶帳戶。

.開始之前
* 您已使用 link:../admin/web-browser-requirements.html["支援的網頁瀏覽器"] 登入 Grid Manager。
* 您有link:admin-group-permissions.html["特定存取權限"]。
* 您已移除與租戶帳戶相關聯的所有 S3 儲存桶和物件。
* 如果允許租戶使用網格同盟連線，您已審查 link:grid-federation-manage-tenants.html["刪除具有「使用網格聯合連線」權限的租戶"] 的考量事項。


.步驟
. 選擇*租戶*。
. 尋找要刪除的租戶帳戶。
+
使用搜尋框依名稱或租戶 ID 搜尋租戶。

. 若要刪除多個租戶，請選取核取方塊，然後選取 *Actions* > *Delete*。
. 若要刪除單一租戶，請執行下列任一操作：
+
** 選取核取方塊，然後選取 *Actions* > *Delete*。
** 選擇租戶名稱以顯示詳細資料頁面，然後選擇 *Actions* > *Delete*。
