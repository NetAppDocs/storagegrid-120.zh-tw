= 管理 StorageGRID 系統
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
請依照以下說明設定和管理 StorageGRID 系統。

這些說明描述如何使用 Grid Manager 來設定群組和使用者、建立租戶帳戶以允許 S3 用戶端應用程式儲存和擷取物件、設定和管理 StorageGRID 網路、設定 AutoSupport、管理節點設定等。

這些說明適用於安裝後將對 StorageGRID 系統進行組態設定、管理和支援的技術人員。

.開始之前
* 您對 StorageGRID 系統有基本的了解。
* 您對 Linux 命令 shell、連網以及伺服器硬體設定和組態有相當詳細的了解。
