= 管理 StorageGRID 中的外部 SSH 存取
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
透過封鎖或允許外部存取來管理傳入網格流量的 SSH 存取。管理 SSH 外部存取不會影響網格中節點之間的流量。

.開始之前
* 您已使用 link:../admin/web-browser-requirements.html["支援的網頁瀏覽器"] 登入 Grid Manager。
* 您有link:admin-group-permissions.html["${post_edited_translations.segment}"]。


.關於此任務
為了增強系統安全性，預設會封鎖外部 SSH 存取。如果您需要執行需要傳入 SSH 存取的工作（例如疑難排解），請暫時允許外部存取。完成工作後，請封鎖外部存取。

.步驟
. ${post_edited_translations.segment}
. 選取 *Block SSH* 索引標籤。
. 使用「封鎖傳入 SSH 存取」選項來管理外部 SSH 存取：
+
.. 選取此核取方塊可封鎖存取（預設）。
.. 取消選取核取方塊以允許存取。
+

NOTE: 需要服務筆記型電腦與所有其他網格節點之間在連接埠 22 上的存取權限。完成維護工作時，請移除連接埠 22 的存取權限。



. 選取 *Save* 。
