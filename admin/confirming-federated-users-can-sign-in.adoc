.開始之前

* ${post_edited_translations.segment}


.步驟
. 如果存在租戶帳戶，請確認沒有租戶使用自己的身分來源。
+

TIP: 啟用單一登入 （SSO） 後，租戶管理員中設定的身分來源將會被 Grid Manager 中設定的身分來源覆寫。除非擁有 Grid Manager 身分來源的帳戶，否則屬於租戶身分來源的使用者將無法再登入。
