= StorageGRID 中已移除或已棄用的功能
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
了解 StorageGRID 12.0 中已移除或棄用的功能和特性。升級前，請檢查已移除或棄用的功能是否會影響您的用戶端應用程式或網格配置。



[[definitions]]
== 定義

已棄用:: 此功能 *不應* 用於新的生產環境。現有的生產環境可以繼續使用此功能。
生命週期結束:: 最後一個支援該功能的已發布版本。在某些情況下，該功能的文件可能會在此階段移除。
已移除:: 第一個*不支援*該功能的版本。




[[storagegrid-end-of-feature-support]]
== StorageGRID 功能支援終止

已棄用的功能將在 N+2 個主要版本中移除。例如，如果某個功能在版本 N （例如 6.3） 中被棄用，那麼該功能存在的最後一個版本是 N+1 （例如 6.4）。版本 N+2 （例如 6.5） 是產品中首次不再包含該功能的版本。

如需更多資訊，請參閱 https://mysupport.netapp.com/site/info/version-support["軟體版本支援頁面"^]。


NOTE: 在某些情況下，NetApp 可能會比預期更早停止對特定功能的支援。
