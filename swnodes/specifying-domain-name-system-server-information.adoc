= 指定 StorageGRID 的 DNS 伺服器資訊
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您必須為 StorageGRID 系統指定 DNS 資訊，以便使用主機名稱而非 IP 位址存取外部伺服器。

.關於此任務
指定 https://docs.netapp.com/us-en/storagegrid-appliances/commonhardware/checking-dns-server-configuration.html["DNS 伺服器資訊"^]後，您可以使用完全限定網域名稱 (FQDN) 主機名稱而非 IP 位址進行電子郵件通知和 AutoSupport。

為確保正常運作，請指定兩到三個 DNS 伺服器。如果指定超過三個，由於某些平台的作業系統限制，可能只會使用其中三個。如果您的環境有路由限制，您可以link:../maintain/modifying-dns-configuration-for-single-grid-node.html["自訂 DNS 伺服器清單"]讓個別節點（通常是站台上的所有節點）使用最多三個不同的 DNS 伺服器。

如果可能，請使用每個站台都可以在本機存取的 DNS 伺服器，以確保孤立的站台能夠解析外部目標的 FQDN。

.步驟
. 在「伺服器 1」文字方塊中指定至少一個 DNS 伺服器的 IPv4 位址。
. 如有必要，請選擇最後一個條目旁邊的加號以新增其他伺服器條目。
+
image:9_gmi_installer_dns_page.gif["這張映像由周圍的文字進行解釋。"]

+
最佳實務做法是至少指定兩個 DNS 伺服器。最多可以指定六個 DNS 伺服器。

. 選擇 *Next* 。
