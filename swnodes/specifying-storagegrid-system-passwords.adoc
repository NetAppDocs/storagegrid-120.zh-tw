= 請指定 StorageGRID 系統密碼
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在安裝 StorageGRID 系統的過程中，您需要輸入用於保護系統安全及執行維護工作的密碼。

.關於此任務
使用「安裝密碼」頁面指定佈建密碼短語和網格管理 root 使用者密碼。

* 佈建密碼短語用作加密金鑰，StorageGRID 系統不會儲存該密碼短語。
* 您必須擁有佈建密碼才能進行安裝、擴充和維護程序，包括下載復原套件。因此，請務必將佈建密碼儲存在安全的位置。
* 如果您有目前的佈建密碼，則可以從 Grid Manager 變更佈建密碼。
* 可以使用 Grid Manager 變更網格管理 root 使用者密碼。
* 隨機產生的命令列主控台和 SSH 密碼儲存在恢復套件的  `Passwords.txt` 檔案中。


.步驟
. 在 *Provisioning Passphrase* 中，輸入對 StorageGRID 系統的網格拓撲進行變更所需的佈建密碼。
+
將佈建密碼短語儲存在安全的地方。

+

NOTE: 如果在安裝完成後，您想要變更佈建密碼，可以使用 Grid Manager。選取 *組態* > *存取控制* > *Grid 密碼*。

. 在「確認佈建密碼」中，重新輸入佈建密碼以進行確認。
. 在「Grid Management Root User Password」中，輸入以「root」使用者身分存取 Grid Manager 的密碼。
+

CAUTION: 請將佈建密碼儲存在安全的位置。安裝、擴充和維護程序都需要用到它。

. 在「確認 root 使用者密碼」中，重新輸入 Grid Manager 密碼進行確認。
+
image:10_gmi_installer_passwords_page.gif["這張映像由周圍的文字進行解釋。"]

. 如果您安裝網格是為了概念驗證或簡報目的，可選擇清除「建立隨機命令列密碼」核取方塊。
+
對於生產環境部署，出於安全性考慮，應始終使用隨機密碼。只有當您希望使用預設密碼透過命令列使用「root」或「admin」帳戶存取網格節點時，才需要清除「建立隨機命令列密碼」選項，該選項僅適用於示範網格。

+

NOTE: 在「摘要」頁面點選 *Install* 後，系統會提示您下載復原套件檔案(`sgws-recovery-package-id-revision.zip`。您必須link:../maintain/downloading-recovery-package.html["下載此檔案"]完成安裝。存取系統所需的密碼儲存在 `Passwords.txt`檔案中，該檔案包含於復原套件檔案內。

. 按一下 *Next* 。
