= 檢查您的 StorageGRID 組態
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您必須仔細審查您輸入的組態資訊，以確保安裝順利完成。

.步驟
. 檢視*摘要*頁面。
+
image:11_gmi_installer_summary_page.gif["Grid Manager 安裝程式摘要頁面"]

. 請確認所有網格組態資訊均正確。使用「摘要」頁面上的「修改」連結返回並更正任何錯誤。
. 點選 *Install*。
+

NOTE: 如果某個節點設定為使用用戶端網路，則按一下 *Install* 時，該節點的預設閘道將從 Grid Network 切換到 Client Network。如果連線中斷，您必須確保透過可存取的子網路存取主要管理節點。如需詳細資訊、請參閱 link:../network/index.html["網路連線準則"]。

. 按一下 *Download Recovery Package*。
+
當安裝進行到定義網格拓撲的階段時，系統會提示您下載 Recovery Package 檔案(`.zip`），並確認您可以成功存取該檔案的內容。您必須下載 Recovery Package 檔案，以便在一個或多個網格節點發生故障時恢復 StorageGRID 系統。安裝會在背景繼續進行，但您必須先下載並驗證此檔案，才能完成安裝並存取 StorageGRID 系統。

. 確認您可以擷取 `.zip`檔案的內容，然後將其儲存在兩個安全且分隔的位置。
+

CAUTION: 復原套件檔案必須受到保護，因為它包含可用於從 StorageGRID 系統取得資料的加密金鑰和密碼。

. 選取 *I have successfully downloaded and verified the Recovery Package file* 核取方塊，然後按一下 *Next*。
+
如果安裝仍在進行中，則會顯示狀態頁面。此頁面指示每個網格節點的安裝進度。

+
image:12_gmi_installer_status_page.gif["這張映像由周圍的文字進行解釋。"]

+
當所有網格節點都達到「完成」階段時，Grid Manager 的登入頁面就會出現。

. 使用「root」使用者和您在安裝期間指定的密碼登入 Grid Manager。
