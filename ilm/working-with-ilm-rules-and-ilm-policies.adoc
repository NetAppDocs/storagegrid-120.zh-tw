= 在 StorageGRID 中使用 ILM 原則和 ILM 規則
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
隨著儲存設備需求的變化，您可能需要制定額外的原則或修改與原則關聯的 ILM 規則。您可以檢視 ILM 計量來確定系統效能。

.開始之前
* 您已使用 link:../admin/web-browser-requirements.html["支援的網頁瀏覽器"] 登入 Grid Manager。
* 您有link:../admin/admin-group-permissions.html["特定存取權限"]。




[[view-ilm-policies]]
== ${post_edited_translations.segment}

檢視作用中和非作用中的 ILM 原則及原則啟動歷史記錄：

. 選擇 *ILM* > *原則*。
. 選擇 *Policies* 以檢視作用中與非作用中原則的清單。此表格列出每個原則的名稱、原則所指派的標籤，以及該原則為作用中或非作用中。
. ${post_edited_translations.segment}
. ${post_edited_translations.segment}
+

NOTE: 如果您檢視狀態為「已編輯」或「已刪除」的原則的詳細資訊，則會顯示一則訊息，說明您正在檢視的是在指定時間範圍內處於作用中狀態、但此後已被編輯或刪除的原則版本。





[[edit-an-ilm-policy]]
[[edit-ilm-policy]]
== 編輯 ILM 原則

您只能編輯停用的原則。如果您想編輯啟動的原則，請將其停用，或建立 Clone 並編輯該 Clone。

${post_edited_translations.segment}

. 選擇 *ILM* > *原則*。
. 選取要編輯的原則對應的核取方塊，然後選取 *Edit*。
. 請按照 link:creating-ilm-policy.html["建立 ILM 原則"] 中的說明編輯原則。
. 在重新啟動原則之前，請先模擬該原則。



CAUTION: 組態設定錯誤的 ILM 原則可能會導致無法復原的資料遺失。在啟動 ILM 原則之前，請仔細審查 ILM 原則及其 ILM 規則，然後模擬該 ILM 原則。務必確認 ILM 原則能夠如預期運作。



[[clone-an-ilm-policy]]
[[clone-ilm-policy]]
== Clone ILM 原則

Clone ILM 原則：

. 選擇 *ILM* > *原則*。
. 選取要 Clone 的原則對應的核取方塊，然後選取 *Clone*。
. 請按照 link:creating-ilm-policy.html["建立 ILM 原則"] 中的說明，從您已 Clone 的原則開始建立新原則。



CAUTION: 組態設定錯誤的 ILM 原則可能會導致無法復原的資料遺失。在啟動 ILM 原則之前，請仔細審查 ILM 原則及其 ILM 規則，然後模擬該 ILM 原則。務必確認 ILM 原則能夠如預期運作。

[[clone-an-ilm-rule]]
[[clone-ilm-rule]]
== ${post_edited_translations.segment}

如果您想要建立使用現有規則某些設定的新規則，可以 Clone 現有規則。如果您需要編輯任何原則中使用的規則，請改為 Clone 該規則，並對該 Clone 進行變更。對 Clone 進行變更後，您可以視需要從原則中移除原始規則，並將其取代為修改後的版本。


NOTE: 如果 ILM 規則是使用 StorageGRID 版本 10.2 或更早版本建立的，則無法 Clone 該規則。

.步驟
. 選擇 *ILM* > *規則*。
. 選取您要 Clone 的規則核取方塊，然後選取 *Clone*。或者，選取規則名稱，然後從規則詳細資料頁面選取 *Clone*。
. 請按照 <<${post_edited_translations.segment},編輯 ILM 規則>> 和 link:create-ilm-rule-enter-details.html#use-advanced-filters-in-ilm-rules["${post_edited_translations.segment}"] 的步驟來更新複製的規則。
+

[[edit-an-ilm-rule]]
== ${post_edited_translations.segment}

您可能需要編輯 ILM 規則來變更篩選器或放置指令。

如果規則已在任何 ILM 原則中使用，則無法進行編輯。但您可以 <<clone-ilm-rule,${post_edited_translations.segment}>> 並對 Clone 複本進行任何必要的變更。


CAUTION: 組態設定錯誤的 ILM 原則可能會導致無法復原的資料遺失。在啟動 ILM 原則之前，請仔細審查 ILM 原則及其 ILM 規則，然後模擬該 ILM 原則。務必確認 ILM 原則能夠如預期運作。

.步驟
. 選擇 *ILM* > *規則*。
. 確認您要編輯的規則未在任何 ILM 原則中使用。
. 如果您要編輯的規則未在使用中，請選取該規則的核取方塊，然後選取 *動作* > *編輯*。或者，選取該規則的名稱，然後在規則詳細資料頁面上選取 *編輯*。
. 完成「編輯 ILM 規則」精靈的步驟。如有必要，請按照 link:create-ilm-rule-enter-details.html["${post_edited_translations.segment}"] 和 link:create-ilm-rule-enter-details.html#use-advanced-filters-in-ilm-rules["${post_edited_translations.segment}"] 的步驟操作。
+
編輯 ILM 規則時，無法變更其名稱。
