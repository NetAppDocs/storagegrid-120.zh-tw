== 關於這些說明

設計與實作 ILM 規則和原則需要仔細的規劃。您必須瞭解您的營運需求、 StorageGRID 系統的拓撲、您的物件保護需求，以及可用的儲存設備類型。然後，您必須確定您希望如何複製、分發和儲存不同類型的物件。

${post_edited_translations.segment}

* 瞭解 StorageGRID 資訊生命週期管理，包括 link:how-ilm-operates-throughout-objects-life.html["ILM 如何在物件的整個生命週期中運作"]。
* 了解如何設定 link:what-storage-pool-is.html["儲存池"]、link:what-cloud-storage-pool-is.html["${post_edited_translations.segment}"] 和 link:what-ilm-rule-is.html["ILM 規則"]。
* 了解如何 link:creating-ilm-policy.html["建立、模擬及啟動 ILM 原則"] 以跨一個或多個站台保護物件資料。
* 瞭解如何 link:managing-objects-with-s3-object-lock.html["${post_edited_translations.segment}"]，這有助於確保特定 S3 儲存貯體中的物件在指定的時間內不會被刪除或覆寫。
